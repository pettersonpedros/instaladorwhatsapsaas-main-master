# Central de Cobrança (mockup)

Mockup navegável do módulo financeiro por licença, para validar com o time financeiro.
Abra `index.html` no navegador. Todos os dados são de exemplo e ficam salvos só no navegador
(botão "Restaurar dados de exemplo" volta ao estado inicial).

Abas: Clientes e licenças (importação por planilha, negociação, Boleto + NF / Só boleto),
Regras de cobrança (regras de valor + régua de lembretes), Cobrança do mês (envio em um clique),
Conciliação (pagos / em aberto / vencidos, NF liberada após pagamento, relatórios agendados),
Pagamentos e Insights (painel configurável).

Cada aba tem um bloco "Validar com o financeiro" com as decisões em aberto.
